## 玩法要点

- **卷宗系统**：主卷公文、立案决定书、讯问笔录卷、询问笔录、证人证言卷、
  鉴定意见书、司法审计卷、资金物证卷、传唤/拘留/逮捕证——逐卷整理。
- **讯问环节**：填写讯问时间、地点、侦查人员、被讯问人，在笔录中比对口供，
  找出**口供矛盾**是推进案件的关键。
- **法律文本**：大量引用《中华人民共和国刑事诉讼法》《中华人民共和国刑法》条款，
  办案流程贴近真实文书格式。
- **资源与压力**：消耗**行动点**推进侦查，积累**政治资本**；上级督办案件
  会带来额外压力。

## 技术说明

- 纯前端单文件，HTML + 内联 JS，样式为 Tailwind（已内联），无构建、无后端。
- 存档在浏览器本地。
